Prepare

Prepare works on the project folder itself. It adds any packages the code imports that are missing from requirements.txt (making code/requirements.txt if there is none), creates the project's venv, installs requirements.txt into it, checks that each package can be imported, and adds a launcher (run.sh, or run.bat on Windows) if there is none. Run it again after changing the imports.
