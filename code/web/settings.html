Settings

Folders must already exist. Enter a full path, such as /home/pi/DWC on Linux or C:\DWC on Windows (~ is fine too). Until you change them, both show the folder this app is installed in (the default). Clear a box, or press Reset to defaults, to go back to it. Create DWC Version puts new versions in the first folder; Create a Plugin reads the DWC versions from it and the plugins from the second.

A relative path, not a full one: the folder holding plugin.json, inside <Plugins folder>/<plugin>/plugin<version>, such as Code. Leave empty for the default: the plugin version folder itself (a leading slash, as in /Code, is fine).
0 means no preference: the first free port from 17800 is used. Otherwise use a port from 1024 to 65535. If your preferred port is already in use, the first free port from 17800 is used instead. A change takes effect the next time the app starts.
There is no login, so on the whole network anyone who can reach the page can run builds and change these settings. Choose this computer only if you use the app from this computer's own browser. Do not choose it on a Pi without a screen: you would no longer be able to open the page from another computer. A change takes effect the next time the app starts.
