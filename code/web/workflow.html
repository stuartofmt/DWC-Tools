Copies the GitHub release workflow for DWC plugins into a plugin's folder on this computer: .github/workflows/release.yml (with its notes, release.yml.md) and the scripts it uses. Only files on disk change: nothing is committed or pushed. The workflow reaches GitHub when you commit and push these files yourself; after that, pushing a version tag builds the plugin's ZIP and publishes a release (see release.yml.md). Copy again at any time to update the workflow: the plugin's own settings files are kept.

The plugin's folder on this computer, at the top of its git checkout (the folder holding .git), with the plugin's plugin.json in it or below it. With no plugin.json, the workflow releases a standalone ZIP of the repository instead.
