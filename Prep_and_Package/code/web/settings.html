Settings

Where Browse starts when no project has been chosen yet (after that it starts next to the last project). It must already exist. Enter a full path, such as /home/pi/DWC on Linux or C:\Projects on Windows (~ is fine too). Clear the box, or press Reset to defaults, to go back to your home folder.
There is no login, so on the whole network anyone who can reach the page can run the project scripts and change these settings. Choose this computer only if you use the app from this computer's own browser. Do not choose it on a Pi without a screen: you would no longer be able to open the page from another computer. A change takes effect the next time the app starts.
